# Cartografía Digital - Rafael Uribe Uribe

Este proyecto es una página web que presenta un mapa interactivo de la localidad Rafael Uribe Uribe en Bogotá, Colombia. El objetivo es visualizar y analizar diversas problemáticas y actividades económicas de la zona a través de marcadores geográficos.

## Tecnologías Utilizadas

*   HTML
*   CSS
*   JavaScript
*   [Leaflet.js](https://leafletjs.com/) - una biblioteca de JavaScript de código abierto para mapas interactivos.

## Uso

Para ver el proyecto, simplemente abre el archivo `index.html` en tu navegador web.
